# TaskFlow – Task Management Application

A simple and interactive task management application designed to help users organize tasks, manage priorities, track progress, and stay productive.

🌐 **Live Demo:** [https://taskflow-five-ivory.vercel.app/](https://taskflow-five-ivory.vercel.app/)

## ✨ Features

- **User Authentication** – Common login system for users and administrators.
- **Task Management** – Create, view, edit, and delete tasks.
- **Kanban Board** – Organize tasks based on their progress.
- **Task Priorities** – Set priority levels for better task management.
- **Due Dates** – Assign deadlines to tasks.
- **Categories** – Organize tasks into different categories.
- **Activity Tracking** – Keep track of task-related activities.
- **Responsive Design** – Works across desktop, tablet, and mobile devices.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- Visual Studio Code

### Installation

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd TaskFlow
```

**3. Install dependencies**

```bash
npm install
```

**4. Start JSON Server**

```bash
npx json-server --watch db.json --port 5000
```

**5. Start the React application**

```bash
npm run dev
```

Open the local URL displayed in your terminal to access TaskFlow.
